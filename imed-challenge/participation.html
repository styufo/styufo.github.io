Checklist before submission

1. Register your team

Create a team entry on the official challenge platform once it is live and make sure your contact email is correct.

2. Review the data usage agreement

The proposal currently lists CC BY for the challenge dataset release. Confirm the final license on the official platform before publishing derivative assets.

3. Validate your Docker image

Test your container with the official loader and evaluation scripts on public data before submitting to the hidden test phase.

4. Document external data use

List all external datasets, pretrained checkpoints, and additional supervision sources in the method report.

5. Submit your structured report

The current proposal asks for a structured methods report and contributor names for possible inclusion in the joint challenge paper.

FAQ

Can we use external public datasets?

Yes. The current policy allows publicly available datasets and pretrained networks, provided they are clearly documented and legally accessible.

Can we use private hospital data?

No. The current proposal explicitly disallows private clinical data and non-public institutional datasets.

Are organizer teams allowed on the leaderboard?

Yes, but they must be clearly marked as organizer-affiliated and are not eligible for awards.

Will there be a public validation phase?

Yes. The proposal describes public validation support using official scripts, baseline code, and intermediate submissions before final hidden testing.

Will code need to be open-sourced?

Open-sourcing is encouraged but not required. Teams must submit executable Docker containers to the organizers.
